# Wolfpack EDC Agent Entrypoint

This repo ships deep architectural context generated by EDC.

Runtime mode: advisory; unmatched paths warn-allow.

Read `edc-context/index.md` first for routing, invariants, and cross-module blast radius. Use `edc-context/manifest.json` as the authoritative routing/policy contract.

## Efficient verification and navigation

- Run `bun run check:context` when context routes change or appear broken. Do not repeatedly retry a missing declared document; report the broken route and inspect the owning source.
- Discover paths, search the owning directory/symbol first, then read bounded source ranges. Broaden or read full files when correctness requires it; relevant diffs and mandatory instructions must remain inspectable.
- Save complete routine test/build output to a unique private artifact. Return actual exit status, command/cwd, revision/dirty state, duration, reliable counts and artifact paths; show bounded diagnostics on failure. Prefer `run_check` when available, otherwise redirect output and preserve the real exit code. `tee` to the tool stream is not context suppression.
- Use focused checks during edits and the required broad gate on the final revision. Independent reviewer reruns and baseline/mutation probes are not redundant. Never reuse results by command string or HEAD alone.
- Keep one current phase handoff with exact base/head, allowed actions, task/session IDs, open decisions and artifact paths. Detailed reports belong in files; use task status at meaningful checkpoints and obey the loaded task-lifecycle skill.
