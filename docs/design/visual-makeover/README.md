# Wolfpack visual makeover

A presentation-only refinement of the existing app, not a navigation redesign. Originally validated against `main` at `70f8689`, and now rebased onto `e8df7be`, preserving onboarding, the default-pinned sidebar, Idle filter, session activity, terminal workflows, and main's distinct grid/session actions.

## Finish

- Retain the original wolf SVG and dark/green identity, with graphite-green surfaces and quieter edges.
- Replace glowing uppercase session names with crisp, case-preserving monospace.
- Use native system UI type for controls and prose; keep commands, paths, previews, and terminal fonts monospace. No new fonts or dependencies.
- Improve secondary-text contrast and remove opacity-based dimming of inactive cards.
- Unify radii, spacing, badges, and control surfaces. Preserve visible stop controls and destructive confirmation.
- Center and bound native dialogs; keep mobile form text at 16px to avoid focus zoom.
- Keep machine names as quiet, muted uppercase monospace labels: 11px in the main list and 10px in the compact sidebar. The initial enlargement was reverted after visual feedback. Long names still truncate and retain their full title.
- Show the original 24px wolf logo in the mobile main banner, without crowding picker or terminal controls.
- Present All/Idle as a compact pill-shaped segmented control with system UI text and a neutral filled selection. Its tightened spacing yields a 102px-wide main pill with 1px inner padding. Align it with the expanded desktop cards; preserve 44px mobile targets, keyboard focus, reduced-motion support, and existing filtering behavior.
- Replace the square `+` with a quieter **New session** action and small SVG icon. Compact multi-machine sidebar buttons show **New**; accessible names still identify the target machine. Mobile hit targets remain 44px high.

`public/styles.css` owns styling. Small shared presentation helpers in `public/app.ts` render escaped names and button markup without changing handlers, machine routing, disabled states, or empty-state onboarding. `src/public-assets.ts` is regenerated by the existing pipeline. Terminal canvas styling, grid/header dimensions, sidebar width, native input, and accessory-key behavior are preserved.
