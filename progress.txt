- 2026-02-25: Completed P0 UX-02 (prompt-aware quick action bar). Added contextual `Yes/No/Enter/Ctrl+C` quick-action chips above the input bar on mobile terminal view. Chips appear when the last 5 lines of terminal output match interactive prompt patterns (y/n, yes/no, Press Enter, Continue?, approve, permission, waiting for input, etc.). Chips auto-hide when output no longer matches. `Yes` sends "yes"+Enter, `No` sends "no"+Enter, `Enter` sends Enter key, `Ctrl+C` sends C-c. Added 43 unit tests for the prompt classifier (`tests/unit/prompt-classifier.test.ts`) covering positive matches, line-window edge cases, negative matches, and real-world agent prompt patterns. Regenerated embedded assets.
- 2026-02-25: Completed UX-03 (per-session draft persistence). Input drafts persisted to localStorage keyed by `wp-draft|{machine}|{session}`. Draft saved on every keystroke, restored on session open/switch, cleared on successful send. Covers session switching, browser backgrounding, and page reload. No cross-session leakage — key includes both machine URL and session name.
- 2026-02-25: Completed UX-04 (terminal follow mode + scroll lock). Mobile terminal no longer yanks viewport when user scrolls up to read history. Follow mode tracks whether auto-scroll is active — disabled on user scroll-up, re-enabled when user scrolls back to bottom or taps "Live" pill button. Programmatic scrolls (from applyTerminalPane) are distinguished from user scrolls via a scrollTop setter patch. Follow mode resets to true on session open. Desktop xterm.js unaffected (handles its own scrollback). Regenerated embedded assets.
- 2026-02-25: Completed UX-05 (session triage signals in list). Added per-session triage classification: `needs-input` (prompt patterns), `error` (error patterns), `running` (tmux activity within 20s), `idle` (otherwise). Server-side classification in new `triage.ts` module, returned as `triage` field from `/api/sessions`. Sessions sorted by triage priority: needs-input > error > running > idle. Frontend renders colored badges (input=yellow, error=red, running=green, idle=gray) next to session names with matching dot colors and card border styling. Added 26 unit tests (`tests/unit/triage.test.ts`) and 7 integration tests covering classification and sorting. Regenerated embedded assets.
