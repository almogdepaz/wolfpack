INSTALL ON YOUR MACHINE

Install Wolfpack.

Install leads into guided setup, which prints a local URL usable without Tailscale. Only after Tailscale sign-in and tailscale serve are verified does setup also print a private Tailnet HTTPS URL and QR code.

  • Supported targets: macOS arm64/x64 and Linux x64/arm64.
  • An agent CLI is optional because Shell works.
  • Tailscale is optional for local-only and required for private phone/remote access.
PERSISTENT CLI

Install once, run anywhere

Downloads verified native binaries, adds a stable command when possible, then opens setup.

curl -fsSL https://raw.githubusercontent.com/almogdepaz/wolfpack/main/install.sh | bash

Verify after setup: wolfpack doctor

NO PATH CHANGE / BUN

Run with Bunx

Use the latest package without installing a persistent global command.

bunx wolfpack-bridge@latest

Verify: bunx wolfpack-bridge@latest doctor

NO PATH CHANGE / NPM

Run with npm

Use the latest package without installing a persistent global command.

npx --yes wolfpack-bridge@latest

Verify: npx --yes wolfpack-bridge@latest doctor

Bunx and npm make no persistent PATH change.

What the installer changes

The native installer downloads matching Wolfpack server and broker binaries from the latest GitHub release and verifies them with checksums-sha256.txt.

It installs the managed binaries under ~/.wolfpack/bin, attempts a best-effort /usr/local/bin/wolfpack symlink, then opens setup.

During setup, you choose the projects directory, port, optional Tailscale remote access, optional Pi integration when Pi is detected, and whether Wolfpack starts at login.

The package-runner options prepare Wolfpack in the package cache but make no persistent PATH change.
